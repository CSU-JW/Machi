# 修复记录（2026-10-05）

对应审查：`docs/project-review-2026-10-05.md`

## 已修复

### P0
- `engine.js` 的 `canBuy` / `canBuild` / 商场交换全部改用 `hasOwnProperty` 安全查表；`__proto__` / `constructor` / `hasOwnProperty` / `toString` / `valueOf` 不会再被当成卡牌或地标。
- `server.js` 的 WebSocket 消息处理加 `try/catch`，坏消息回 `INTERNAL_ERROR` 而不是崩溃。
- `WebSocketServer` 加 `maxPayload: 64KB`。
- 新增 `test/security.test.js`，13 条回归测试覆盖上述原型键与商场交换。

### P1
- 新增回合超时托管：`turnTimeoutMs`（默认 60s）、掉线托管 `disconnectedTurnTimeoutMs`（默认 12s）。
- 超时或掉线时由普通难度 AI 替当前玩家完成整回合（掷骰、重掷、体育馆/电视塔/商场、购卡、建设、结束回合），避免对局永久卡死。
- 服务关闭时清理所有房间计时器。
- 新增两条集成测试：挂机超时推进、掉线托管推进。

### P2
- `rules.txt` 的麦田/面包店上限同步为代码值 14 / 12，并新增 `test/rules-doc.test.js` 锁定文档与代码一致。
- `handleJoinRoom` 插入后无条件 `reindexWaitingRoom`，修复「带人机房再加入真人后无法移除人机」。
- `broadcastGame` 与 `engine.log` 把日志截断到 500 条。
- `scripts/build-images.mjs` 支持 `--force`，并改为从 `assets-src/` 读取原始图。
- `auth-store.js` 在账号文件损坏时先备份为 `accounts.json.corrupt-<ts>`，不再静默覆盖。
- 登录/注册加按设备/窗口的限流（默认 20 次/60s）。
- 原始卡图（30 张，40.2MB）移到 `assets-src/`（已加入 `.gitignore`）；部署资源从 44.6MB 降到 5.28MB，DLC 预览页改用 512 WebP。

### P3 / UI
- DLC 角色/任务选择改成居中弹层，并加 30 秒倒计时。
- 对局记录加折叠开关。
- 窄屏（≤1200px）自动缩小中间牌堆卡片；移动端竖排背景改 `cover`。
- 删除死代码 `escapeHtml`。
- 新增 `/api/catalog`，客户端启动时用服务端目录覆盖卡牌名称/点数/价格与 `SIX_CARDS`（图片文件名仍是客户端映射）。
- `package.json` 的 `main` 改为 `server.js`，新增 `engines.node >= 18`。
- 新增 `.github/workflows/test.yml`，push/PR 自动跑 `npm test`。

### 规则 / 平衡
- 机器人期望改成与引擎一致：按卡牌张数、按 `ceil(raw × max(pt/6,1))` 计算，修正了之前忽略张数与 `take` 类收益的问题。
- 便民服务只在基础回合真正结束时结算一次；广播中心额外回合不再重复触发（更新了对应测试）。
